这篇不是真的笔记，是**记笔记的模板**，以后照着这个结构写就行。

## 模板

```
# 第 X 章：主题名

## 一句话总结

这章到底在讲什么（用自己的话写一句）。

## 核心概念

- 概念 A：定义 + 为什么需要它
- 概念 B：定义 + 和 A 的区别

## 关键推导 / 流程

（公式、步骤，能画图就画图）

## 我卡住的地方

- 哪里没懂、后来怎么想通的

## 课后思考

- 这个知识点能用在哪
```

## 为什么用这个结构

- **一句话总结**逼你真的理解，而不是抄书
- **我卡住的地方**最有价值——一个月后复习，你只需要看这一节
- **课后思考**把知识点和实际问题连起来

## 一点经验

笔记不是抄课件。抄一遍课件只是练打字；**合上书用自己的话重写一遍**才算学会。

{: .prompt-tip }

> 写不出来的时候，往往就是没真懂的地方，正好标记下来去问。
