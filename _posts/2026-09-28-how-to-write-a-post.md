这篇是写给未来的自己的备忘：**发文章只需要三步**。

## 第一步：新建文件

在仓库的 `_posts/` 目录下新建文件，文件名必须是：

```
年-月-日-英文标题.md
```

例如 `2026-10-01-python-data-visualization.md`。日期要真实（决定排序），标题用英文或拼音，中文标题写在文件里面。

## 第二步：写开头信息（Front Matter）

每篇文章开头都要有这段用 `---` 包起来的内容：

```
---
title: 文章标题（这里可以写中文）
date: 2026-10-01 10:00:00 +0800
categories: [课程笔记]
tags: [Python, 数据分析]
---
```

- `categories`：分类，建议从这几个里选一个 —— `课程笔记`、`项目`、`踩坑记录`、`随想`、`教程`
- `tags`：标签，可以随便加，方便以后检索
- `date`：发布时间，别填将来的日期，否则文章不会显示

## 第三步：写正文，然后推送

正文就是普通 Markdown。写完把文件推到 GitHub，等 1～2 分钟刷新，文章就出现了。

推送方式：打开 GitHub Desktop → 左下角写一句摘要 → **Commit to main** → **推送 origin**。

## 常用 Markdown

| 想做的事 | 写法 |
| --- | --- |
| 标题 | `## 二级标题` |
| 加粗 | `**文字**` |
| 链接 | `[文字](网址)` |
| 图片 | `![说明](/assets/img/xxx.png)` |
| 引用 | `> 文字` |
| 代码块 | 首尾各用一行三个反引号包起来，开头那行反引号后面写语言名（如 python） |

## Chirpy 的小技巧

- 想加提示框：`{: .prompt-tip }`、警告框 `{: .prompt-warning }`，写在段落末尾
- 想折叠一段内容：用 `<details><summary>点开看</summary>内容</details>`
- 图片放 `assets/img/`，引用时写 `![说明](/assets/img/文件名.png)`

---

小提醒：**不要一次想写完美**。先把想法记下来发出去，以后想改随时改。
