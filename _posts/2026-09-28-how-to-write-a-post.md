这篇是写给未来的自己的备忘：**发文章只需要三步**。

## 第一步：新建一个 Markdown 文件

在仓库的 `_posts/` 目录下新建文件，文件名必须长这样：

```
年-月-日-英文标题.md
```

比如 `2026-10-01-my-first-python-script.md`。日期必须是真实日期，中文标题可以写在文件里面（见下一步），文件名用英文或拼音，避免网址出现乱码。

## 第二步：在文件开头加上"头信息"

每个文章文件的开头都要有一段用 `---` 包起来的信息，叫 Front Matter：

```
---
layout: post
title: 文章标题（这里可以写中文）
date: 2026-10-01 10:00:00 +0800
tags: [标签1, 标签2]
---
```

- `title`：显示在首页和浏览器标签上的标题
- `date`：发布时间，决定文章排序
- `tags`：标签，首页会显示成小圆标签；不想加就写 `tags: []`

## 第三步：写正文，然后推送

正文就是普通的 Markdown：

````
# 一级标题
## 二级标题

**加粗**、`代码`、[链接](https://example.com)

- 列表项
- 列表项

> 引用

```python
print("代码块")
```
````

写完把文件推到 GitHub，等大约 1 分钟刷新，文章就出现在首页了。

## 常用 Markdown 速查

| 想做的事 | 写法 |
| --- | --- |
| 标题 | `## 标题` |
| 加粗 | `**文字**` |
| 斜体 | `*文字*` |
| 链接 | `[文字](网址)` |
| 图片 | `![说明](图片地址)` |
| 引用 | `> 文字` |
| 分割线 | `---` |

## 图片放哪儿

在仓库里建一个 `assets/images/` 目录，把图片放进去，文章里这样引用：

```
![示意图](/assets/images/demo.png)
```

---

小提醒：**不要一次想写完美**。先把想法记下来发出去，以后想改随时改，文章会保留修改记录。
